这是 Chrome 多开管理器的源码开发版，当前暂不打包 EXE，方便继续开发和调试。

复制到新电脑后的使用方法：

1. 安装 Google Chrome 和 Python 3.11 或更高版本。
2. 第一次运行先双击“安装开发依赖.cmd”。
3. 双击“打开Chrome多开管理器.cmd”。
4. 点击“新建浏览器”，输入名称和端口。
5. 选择浏览器后点击“启动选中”，第一次打开时自行登录网站。

源码文件：

- ChromeManager.pyw：主程序源码
- browser_cli.py：供 Codex 或命令行新增、列出、启动和关闭浏览器
- environment_config.py：浏览器环境配置、启动参数和一致性规则
- environment_controller.py：通过本地 CDP 将环境设置应用到现有和新标签页
- proxy_forwarder.py：为带账号密码的 HTTP 代理提供本地认证桥
- requirements.txt：开发依赖

Codex 协作：

Codex 新增浏览器时，应在本目录运行：

python browser_cli.py add --name "店铺A"

管理器会在约 4 秒内自动读取 browser-map.json，并显示新浏览器。

列出浏览器：

python browser_cli.py list

启动指定浏览器：

python browser_cli.py start 9231

关闭指定浏览器：

python browser_cli.py stop 9231

程序启动的浏览器带固定 CDP 端口，因此 Codex、Playwright 或 agent-browser 都能连接操作。

功能：

- 新建浏览器：创建新的独立浏览器
- 编辑浏览器：设置分组、首页、代理、备注、自动启动、定时启动和浏览器环境
- 复制浏览器：复制现有 profile，建立新的独立环境
- 删除浏览器：可选择保留或删除 profile 数据
- 启动选中：启动当前选中的浏览器
- 全部启动：同时启动全部浏览器
- 多选批量操作：按 Ctrl 或 Shift 选择多个浏览器
- 关闭选中：关闭当前选中的浏览器
- 打开网页：在选中浏览器中打开网址
- 运行监控：显示 PID、标签页数量和内存占用
- Codex 指令：自动生成并复制指定端口的操作指令
- 浏览器环境：UA、窗口、语言、时区、定位、权限、下载目录、颜色模式、移动/触摸模式和独立扩展
- 网络隐私：独立代理、安全 DNS、WebRTC 限制和代理出口检测
- 隐私测试覆盖：Canvas、WebGL、CPU、内存和字体的页面级测试覆盖
- 环境实测：在浏览器内显示当前 UA、语言、时区、分辨率、硬件可见值和公网 IP
- 一致性检查：提示代理地区、语言、时区、移动模式和隐私覆盖之间的冲突
- 数据清理：清除选中浏览器的缓存、Cookie 和历史记录
- 备份恢复：完整导出单个浏览器、导入为新浏览器或恢复到现有浏览器
- 导入导出：迁移浏览器配置和程序设置
- 管理器密码：启动时验证密码
- 系统托盘：关闭主窗口后在任务栏右下角继续运行
- 单实例保护：重复打开管理器时不会产生多个后台进程
- 开机启动：Windows 登录后自动运行管理器
- 日志记录：记录创建、启动、关闭、备份和迁移操作
- Chrome 更新入口：在指定浏览器中打开更新页面

程序会自动创建：

- profiles：每个浏览器独立的 Cookie、登录状态、书签、扩展和缓存
- launchers：每个浏览器可单独双击的启动器
- backups：默认备份目录
- browser-map.json：名称、端口和 profile 映射
- manager-settings.json：托盘、管理器密码等程序设置

向 Codex 下达任务示例：

连接 9231 的店铺A浏览器，打开 EasyBoss 查询订单。只操作 9231，完成后不要关闭浏览器。

迁移：

完全关闭所有浏览器后，复制整个文件夹到另一台电脑。登录状态可能受 Windows 加密保护，换电脑后部分网站需要重新登录。

重要：必须复制整个文件夹，尤其是 profiles 和 browser-map.json。

安全：

CDP 端口只绑定 127.0.0.1，不要通过防火墙或路由器开放到公网。
代理账号密码、密码管理器和浏览器配置均可能包含敏感明文，请勿把带个人数据的目录上传到 Git。

风险说明：

- TLS 指纹由 Chrome、操作系统和网络栈共同决定，本程序不能可靠伪装。
- Canvas、WebGL、CPU、内存和字体覆盖只适合开发测试或隐私最小化，不等于真实硬件。
- 虚构或固定值可能形成异常组合，反而增加识别风险。
- 本程序不能保证绕过店铺关联检测、模拟多个真实自然人或保证平台无法识别同一设备。
